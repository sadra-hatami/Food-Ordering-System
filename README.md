# 📖 About

**Food Ordering System** is a console program written in C++.

It asks for a name, then opens a five-part menu. The customer picks a category, an item, and a quantity. Pizza also asks for a size. The program prints the line, the total, and a delivery note, then asks if another item should be added.

Prices and item names are fixed in the source. There is no file and no account.

> **Tagline:** *A C++ console program that takes a food order and prints the bill.*

---

# 🚀 Why This Project?

A food menu is a clean place to practice nested choices and a running total.

This one keeps that scope:

- A name, then a category
- Item, size, and quantity
- A printed bill
- A yes or no question for another item

It is a study program, not a restaurant service. The shop name printed in the source is only a sample label.

---

# ✨ Key Features

- 👤 Customer name
- 🍕 Pizzas, with small, regular, and large
- 🍔 Burgers, sandwiches, rolls, and biryani
- 🔢 Quantity
- 🧾 Total bill
- 🔁 Order another item
- 💻 Console only

---

# 🎮 Menu

1. Pizzas
2. Burgers
3. Sandwich
4. Rolls
5. Biryani

Pizza sizes in the program are Small, Regular, and Large. Other categories use a fixed price per item. After the bill, the program asks `Y / N` for another order.

# 🚀 Build

```bash
git clone https://github.com/sadra-hatami/Food-Ordering-System.git
cd Food-Ordering-System
g++ Food_Ordering_System.cpp -o food
./food
```

On Windows, MinGW can build the same file.

---

# ▶️ Usage

1. Build and run.
2. Enter a name.
3. Pick a category, an item, and a quantity.
4. Read the bill.
5. Choose `Y` to add another item, or `N` to stop.

---

# 📝 Notes

- Orders are not saved. Closing the program clears them.
- Prices are written in the source, in rupees.
- The delivery line is a fixed message, not a real dispatch.
- This is a practice desk, not an online order service.
